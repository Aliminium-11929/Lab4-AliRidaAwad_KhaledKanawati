School Management System
=========================

Lab 3 documentation for the Python school management system from Lab 2.
The project includes object-oriented models, SQLite persistence, a Tkinter
interface, and a PyQt5 interface. Both GUIs include explicit enrollment
management, search, file export/import, and database backup/restore controls.
